O que podemos concluir

Neste trabalho

  • exp_05 teve o melhor resultado apresentado.
  • Bilateral foi o melhor filtro no teste.
  • Com o mesmo treino, RGB superou os filtros.

Na comparação entre trabalhos

Os datasets e as avaliações são diferentes.

F1 do trabalho 1 não equivale a mAP do trabalho 2.

Para medir a diferença entre os métodos, ambos precisam ser avaliados na mesma base.

A mudança demonstrada é de abordagem. Os resultados atuais não isolam o efeito da arquitetura.
